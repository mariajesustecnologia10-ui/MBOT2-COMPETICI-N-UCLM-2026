# MBOT2-COMPETICI-N-UCLM-2026
This project, created by IESO students for the UCLM Robotics competition, uses the MBOT2 robot and the mBlock v5.6.0 program. It consists of several missions for the robot, including line following and interaction with different colors, movement of detected objects, and light detection and interaction.

En el código vemos en las zona inferior, el primer paso que hemos conseguido, seguir la línea negra. Para ello vamos dando instrucciones según la detección de color negro del sensor RGB. Lo ideal es que la línea negra sea detectada por los sensores centrales R1 Y L1 mientras que el color blanco debe estar en los sensores exteriores R2 y L2. Este es el momento ideal para que nuestro robot avance. En caso de que se esté detectando que se sale por la derecha, movemos más lentamente el motor de la izquierda y más rápido el de la derecha para que vuelva a centrarse en la línea. Lo mismo si es en el otro sentido, solamente que le diremos que se introduzca de nuevo en la linea haciendo que ande más despacio el motor oportuno.
En cuanto a la detección del color verde hemos tenido diversos problemas. Finalmente hemos decidido empezar el código con establecer modo de color estandar y establecer color de luz roja porque es experimentalmente como mejor nos ha funcionado. Entendemos que es así porque la luz roja sobre luz verde hace que se detecte perfectamente.
Hemos dicho al robot que si el sensor R2 detecta color verde(hemos usado el R2 porque en nuestro circuito a seguir la linea aparece en el lateral verde)pare. Hemos hecho que en la pantalla aparezca escrito si detecta color verde o no, así sabemos si el sensor está funcionando bien(por eso aparece el bloque de escriba y pase a la siguiente línea)
Una vez detectado verde hemos calculado el tiempo que debe avanzar el motor para proceder a un giro de 90º y situarse sobre la línea verde. 
Después le damos las mismas ordenes siguiendo la línea verde (detectándo el color)que le dábamos cuando queríamos seguir la línea negra pero con una excepción; en este caso el robot sigue la línea verde dejándola a su izquierda. Lo ideal es que detecte 1000, es decir, verde-blanco-blanco-blanco (en este caso marrón). Así el sensor L2 es clave y debe ir sobre verde siempre.
