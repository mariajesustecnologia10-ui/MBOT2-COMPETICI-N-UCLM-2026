# MBOT2-COMPETICI-N-UCLM-2026
This project, created by IESO students for the UCLM Robotics competition, uses the MBOT2 robot and the mBlock v5.6.0 program. It consists of several missions for the robot, including line following and interaction with different colors, movement of detected objects, and light detection and interaction.
